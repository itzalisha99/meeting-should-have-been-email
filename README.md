One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny. A judge model reads entries in pairs and keeps the funnier line.

## Entry

> We spent an hour deciding the next meeting should have been an email, then scheduled it anyway.

## How it works

`main.py` writes the single joke line to `/output/entry.txt`, after checking it against the bounty gate (UTF-8 text, 1–200 characters, not only white space, one line).

```sh
python3 main.py
```
